## [💻 Capital Daark](https://capitaldaark.com.br/login)

Seja bem-vindo ao CapitalDaark, um portal digital futurista com uma estética cyberpunk e funcionalidades avançadas de um sistema moderno. Este projeto é uma plataforma web full-stack desenvolvida com as tecnologias mais robustas e atuais do mercado, focada em segurança, alta performance, experiência do usuário (UX) e design imersivo.

O objetivo do CapitalDaark é simular um ambiente restrito de notícias e e-commerce focado em tecnologia de ponta, entregando a experiência de um painel de controle (dashboard) profissional, acessível apenas a usuários registrados.

## 🛠️ Tecnologias Utilizadas

Este projeto evoluiu para uma arquitetura moderna **Serverless/BaaS**, utilizando um frontend altamente reativo e um backend gerenciado focado em escalabilidade.

### Frontend
- **React & Vite:** Construção de interfaces de usuário com build extremamente rápido.
- **TypeScript:** Tipagem estática para um código mais seguro e previsível.
- **Tailwind CSS & shadcn/ui:** Estilização utility-first combinada com componentes acessíveis e customizáveis.
- **React Query (TanStack Query):** Gerenciamento inteligente de estado assíncrono, cache de dados e requisições.
- **React Hook Form & Zod:** Gerenciamento de formulários performático com validação de esquemas fortemente tipados.
- **React Router:** Roteamento de páginas e proteção de rotas (Private Routes).
- **Recharts & Embla Carousel:** Visualização de dados em gráficos interativos e componentes ricos de UI.

### Backend & Banco de Dados (Supabase)
- **Supabase (PostgreSQL):** Banco de dados relacional de alta performance open-source, substituindo soluções tradicionais NoSQL.
- **Supabase Auth:** Sistema de autenticação completo e seguro, gerenciando sessões e tokens nativamente.
- **Row Level Security (RLS):** Regras de segurança aplicadas diretamente no banco de dados para garantir a privacidade dos dados de cada usuário.

### Deploy & Infraestrutura
- **Vercel / Netlify:** Hospedagem otimizada para o frontend com suporte a Serverless Functions.
- **Supabase Cloud:** Hospedagem escalável para o banco de dados e serviços de backend.

## ✨ Funcionalidades Principais

- **Autenticação Segura:** Sistema completo de registro, login e gerenciamento de sessões utilizando Supabase Auth.
- **Dashboard e Visualização de Dados:** Gráficos interativos integrados para visualização de métricas (utilizando Recharts).
- **Rotas Privadas:** Páginas exclusivas (user-home, loja, configurações) protegidas contra acesso de usuários não autenticados.
- **Loja de Produtos:** Espaço com produtos de alta tecnologia, demonstrando o fluxo e funcionalidades de um e-commerce moderno.
- **Design Cyberpunk & Dark Mode:** Interface altamente imersiva com suporte nativo a temas (Dark/Light mode) e micro-interações responsivas.
- **Formulários Type-Safe:** Experiência fluida e livre de erros no frontend com validação rigorosa através de Zod.
